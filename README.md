One ingredient, one picture: a single ripe strawberry, cut in half and shot
macro-close, filling the frame. Glistening red flesh and juice, pale achenes
around the rim, dew droplets on the cut face, a green calyx on top, warm
directional light against dark slate — no text, the picture alone does the
work.

`main.py` (Python 3.13, standard library only) draws the image procedurally
and writes it to `/output/entry.png`: 1024×1024 PNG, deterministic — repeated
runs are byte-identical. Run it with:

```
python3 main.py            # writes /output/entry.png
python3 main.py out.png    # writes to a path of your choice
```
